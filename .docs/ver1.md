- create a project python
- configruation file will contain
	- BOT_KEY={ENVIRONMENT_VARIABLE_NAME}
	- CHAT_IDS=1123123, 1313132, 42423
	- OBSIDIAN_PATH=...
	- MEDIA_PATH=...
	- DAILY_NOTE=/path/{YYYY}/{MM}/{YYYY-MM-DD}.md
- бот будет добалвться в телеграм группу
- бот будет запускаться раз в день и выкачивать новые сообщения (медиа файлы или ещё что-то) и затем скачивать их в папку MEDIA_PATH
- список чатов, которые слушать (нельзя слушать другие чат, даже если бота добавят в них - просто игнорировать сообщения из них, только те, что в конфигурации)
- сделать базу данных локальную, в которой сохранять все статусы
	- пришло новое сообщение - добавить в базу 
		- message path
		- status = new
- когда все сообщения прочитаны из телеграма переходить к фазе обработки
- скачивается файл и кладётся в папку MEDIA_PATH (названия файла - датавремя_чатайди_мессаджайди, в общем уникальное)
- затем запускаем перевод аудио в текст и кладём в папку OBSIDIAN_PATH/inbox
	- когда началась обработка сообщения - в базе статус status = in progress
	- название дата_время_чатайди
	- в шапке сделать formatter (obsidian properties) > и включить
		- created: yyyy-mm-dd
		- id: GUID
		- url: путь к сообщению в телеграм (ссылка)
- когда обработка завершена
	- в базе сообщение со статусом status = done
	- в базе путь path = путь к документу
	- в телеграме выслать ответ на сообщение и дать ссылку на обсудиан, где сохранилось сообщение и его гуид
- повторить обработку для всех не обработанных сообщений
